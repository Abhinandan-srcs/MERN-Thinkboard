# ThinkBoard 📝

ThinkBoard is a full-stack notes application built using the MERN stack. It provides secure authentication, note organization features, and a modern user experience.

## Features

- Secure authentication with Clerk
- Create, edit, and delete notes
- Labels for note organization
- Archive and Trash management
- Dark/Light theme support
- RESTful API with Express.js and Node.js
- Distributed rate limiting using Upstash Redis

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- Clerk Authentication
- Upstash Redis
- Render
